# Student photos for the staircase

Add up to six photos here. Use exactly these names (any of .jpg, .jpeg, .png, .webp):

| File name | Shown on step |
|---|---|
| `classroom` | Classroom |
| `school` | School exhibition |
| `district` | District |
| `state` | State |
| `national` | National |
| `international` | International |

A step with no photo keeps its plain colour, so you can add photos one at a time.

**Size tips:** landscape or square, about 1200 px wide, under 300 KB each. A dark layer is added automatically so the white text stays easy to read.

**Student privacy:** these are children, and the repository is public. Before you upload:
- Get written permission from parents and from the school.
- Prefer photos of hands, projects and group work from behind, not close-up faces.
- Do not add names, ID cards or other personal details in the photo or the file name.
- Remove location data from the photo (EXIF) before uploading.
